# Work order process

## Statuses
A work order is planned when created, in progress when production starts on a line, and completed when all units are finished and passed quality checks. A work order on hold is paused, for example while waiting for materials.

## Overdue work orders
A work order is overdue when its due date has passed and it is not completed. Production planners review overdue work orders every morning. Work orders on hold for more than 5 days must be escalated to the production manager.

## Production lines
Work is assigned to production lines such as Line A, Line B and Line C. A line can run one work order at a time. If a line is busy, the planner should assign the work order to another free line or reschedule the due date.

## Quality checks
Every completed work order needs a quality check before it is closed. If more than 2 percent of units fail, the work order is reopened and set back to in progress until rework is finished.
